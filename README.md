# 🎵 HyperLink - Smart Link Page для саунд-продюсера Timur и лейбла TimurSounds

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.115-green)](https://fastapi.tiangolo.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow)](LICENSE)

Современная платформа для агрегации всех ссылок артиста в одном месте. Создана как аналог BandLink с расширенными возможностями управления.

![HyperLink Preview](static/preview.png)

## ✨ Возможности

- 🎯 **Единая страница** для всех социальных сетей и музыкальных платформ
- 🎵 **Поддержка площадок**: Звук, Яндекс Музыка, Spotify, YouTube, TikTok
- 📅 **Ближайшие релизы** с pre-save ссылками
- 📰 **Новостная лента** с управлением от администратора
- 🔐 **Защищенная админ-панель** с авторизацией
- 💾 **SQLite база данных** - легкая и не требует настройки
- 🎨 **Стеклянный дизайн** с современным UI/UX
- 📱 **Полностью адаптивный** под мобильные устройства
